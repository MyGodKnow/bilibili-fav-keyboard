# bilibili-fav-keyboard

用键盘操作 B 站收藏夹的油猴脚本：在视频页按 `E` 呼出收藏夹面板后，`↑` `↓` 选择收藏夹，`空格` 加入 / 移除，`回车` 保存。

鼠标点收藏按钮也能用，脚本会自动接管已经打开的面板。

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（或 Violentmonkey）。
2. 打开脚本文件 [bilibili-fav-keyboard.user.js](./bilibili-fav-keyboard.user.js)，点右上角 Raw，Tampermonkey 会弹出安装页。
3. 刷新任意 B 站视频页。

## 使用

| 按键 | 作用 |
| --- | --- |
| `E` | 呼出收藏夹面板（面板由 B 站自己打开，脚本只负责接管） |
| `↑` `↓` | 在收藏夹之间移动，目标收藏夹下方显示蓝色下划线 |
| `空格` | 把当前视频加入 / 移出该收藏夹 |
| `回车` | 保存并关闭 |
| `Esc` | 关闭面板 |

面板打开时，页面底部会出现一条提示，显示当前序号（如 `3/8`）、收藏夹名字和快捷键说明。

生效页面：视频页、番剧、播放列表、课程（`bilibili.com/video/*`、`/bangumi/play/*`、`/list/*`、`/cheese/play/*`）。

## 实现要点

- **不依赖写死的 class**：先试已知选择器，失败则按"一列高度一致的兄弟行"探测，再用复选框反推每一行；B 站改版后一般仍可用。
- **识别失败必定输出诊断**：控制台会打印按 `E` 后新增 / 变化的节点表格，以及"新建收藏夹"节点的 `outerHTML`，把日志贴出来即可按真实结构补选择器。
- **下划线由脚本自己绘制**：用「复选框 + 文字的联合矩形」定位一个 `fixed` 元素，因此即使行元素高度异常也不会画偏；滚动时直接跟位，行越出面板可视区时自动收起。
- **不干扰播放器**：只在面板打开期间拦截方向键 / 空格 / 回车；关闭后立刻松开，并把焦点放回 `body`，保证 B 站的左右键快进和上下键音量都正常。

## 常见问题

**按 `E` 没反应，或者方向键变成了调音量？**

说明没识别到收藏夹面板（方向键落到播放器上就变成了调音量）。打开 F12 控制台，看 `[收藏夹键盘]` 开头的输出，里面会有探测到的节点列表和"新建收藏夹"节点的 `outerHTML`，提 issue 时附上即可。

**想要更详细的日志？**

把脚本顶部的 `DEBUG` 改成 `true`。

**B 站改版后失效了？**

按上面的方法抓日志，然后改脚本里的 `DIALOG_SELECTORS` / `ITEM_SELECTORS`，或直接提 issue。

## 兼容性

在 Chrome / Edge + Tampermonkey 下验证。

可见性判断用到 `Element.checkVisibility()`（Chrome 105+），不支持时自动退回几何判断，功能不受影响。
